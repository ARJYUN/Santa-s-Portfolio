## 🎁 Overview

Welcome to Santa's official portfolio! This magical website showcases Santa's journey, workshop, and provides a way to get in touch with the big man himself. Built with modern web technologies, this portfolio brings the holiday spirit to life with beautiful animations and interactive elements.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎄 **Festive Design** | Responsive layout that works on all devices, from sleigh tablets to workshop computers |
| 🕰️ **Interactive Timeline** | Journey through Santa's history from St. Nicholas to the present day |
| ✉️ **Wish List** | Special contact form for submitting your Christmas wishes |
| ❄️ **Winter Magic** | Beautiful winter-themed animations and effects |
| � **Workshop Showcase** | Peek into Santa's workshop and see the magic happen |

## 🚀 Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with custom themes
- **Animations**: Framer Motion
- **Icons**: Lucide Icons
- **Form Handling**: React Hook Form
- **Code Quality**: ESLint + Prettier

## 🎯 Quick Start

### Prerequisites

- Node.js 16+ & npm 8+
- Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/santa-portfolio.git
cd santa-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## 🏗️ Building for Production

```bash
# Create production build
npm run build

# Preview production build
npm run preview
```

## 🎨 Customization

### Theme Colors
Update the holiday color scheme in `tailwind.config.ts`:

```typescript
theme: {
  extend: {
    colors: {
      'christmas-red': '#E31837',
      'christmas-green': '#1E792C',
      'christmas-gold': '#FFD700',
    }
  }
}
```

### Content Updates
- **Text Content**: Edit the respective component files in `src/components/`
- **Images**: Replace images in `public/` directory
- **Animations**: Adjust animation parameters in motion components
